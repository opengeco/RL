Configura l'agente eventi

Tre passaggi. I dati inseriti qui restano nel tuo browser e vengono inviati solo a Facebook.

1 · Crea l'app su Meta (una volta sola)

  1. Apri developers.facebook.com → Crea app, caso d'uso Altro, tipo Business.
  2. Nella dashboard aggiungi il prodotto Instagram → API con accesso tramite Facebook.
  3. In Impostazioni app → Di base copia ID app e Chiave segreta e incollali qui sotto.

2 · Genera un token

  1. Apri il Graph API Explorer e a destra scegli la tua app.
  2. In Permissions aggiungi: instagram_basic pages_show_list pages_read_engagement business_management
  3. Clicca Generate Access Token, seleziona la tua Pagina e il tuo Instagram, poi copia il token (inizia con EAA).

3 · Incolla e premi Configura

    Fatto! Ultimo passo

    1. Copia il token qui sotto.
    2. Apri GitHub → nuovo secret, come Name scrivi META_TOKEN e come Secret incolla il token. Se il secret esiste già, aprilo e clicca Update.
